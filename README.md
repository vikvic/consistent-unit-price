# Consistent Unit Price

A planned Chrome and Firefox extension that displays supported retail prices in one user-selected unit, making products easier to compare.

**Product promise:** Choose your unit once. Compare every supported price on the same basis.

Initial scope: desktop browsers, Amazon.com and Walmart.com, US dollars, and products sold by weight.

See [the implementation plan](docs/PLAN.md) for product rules, architecture, milestones, manual verification, and release criteria.

Status: planning only; no extension code has been implemented.
